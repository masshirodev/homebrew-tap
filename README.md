# masshirodev/homebrew-tap

Homebrew formulae for [ranma](https://github.com/masshirodev/ranma), a tiling
window manager for the terminal.

```sh
brew install masshirodev/tap/ranma
```

After an upgrade (`brew upgrade ranma`), check your config against the new
build and move running servers onto it:

```sh
ranma --check-config && ranma upgrade --all
```

Linux only for now (x86_64 and aarch64); macOS is coming.

## Maintaining

Nothing here is edited by hand. `Formula/ranma.rb` is generated by
[`packaging/brew/formula.sh`](https://github.com/masshirodev/ranma/blob/main/packaging/brew/formula.sh)
in the ranma repository and pushed by its release workflow after each release
(`doc/RELEASING.md` there, "The other channels"). Change the formula in that
script, not here.
